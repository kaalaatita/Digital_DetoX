# Цифровой детокс PWA

Мобильное PWA-приложение для добровольного времени без телефона. Данные MVP хранятся локально в браузере.

## Запуск локально

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

## Публикация на Vercel

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него содержимое этого архива (файлы `package.json` и `pnpm-lock.yaml` должны лежать в корне).
3. В Vercel выберите **Add New Project → Import Git Repository** и укажите этот репозиторий.
4. Оставьте настройки Next.js по умолчанию и нажмите **Deploy**.

Переменные окружения для текущей версии не требуются. После деплоя Vercel выдаст HTTPS-ссылку, которую можно открыть на телефоне и установить приложение на главный экран.

## Установка на Android как PWA

После публикации откройте HTTPS-ссылку в Chrome на Android и выберите **Установить приложение** или **Добавить на главный экран**. В manifest уже подключены Android-иконки `192×192`, `512×512` и maskable-версия с облаком.

Это установка PWA на Android, а не отдельный APK: приложение запускается в standalone-режиме и обновляется при публикации новой версии на Vercel.

## Сборка отдельного Android APK

В репозиторий добавлены `capacitor.config.json` и workflow `.github/workflows/android-apk.yml`. После загрузки проекта в GitHub:

1. Откройте вкладку **Actions** в репозитории.
2. Запустите workflow **Build Android APK** или отправьте изменения в ветку `main`.
3. Дождитесь успешного завершения сборки.
4. Откройте готовый запуск и скачайте артефакт **digital-detox-android-apk**.

Внутри будет один файл `app-debug.apk`. Перенесите его на Android-телефон и разрешите установку приложений из этого браузера или файлового менеджера. APK устанавливается на современные Android-устройства, но для публикации в Google Play в дальнейшем потребуется подписанный release-вариант.

## Важно

История сессий хранится в `localStorage`, поэтому данные пока не синхронизируются между устройствами.
